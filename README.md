# 遥控器使用说明

### 		开关方式及电源：

​				屏幕右侧按键，按一下开机，连按两下关机；

​				屏幕下方四个led为电量显示，可使用5v电源链接遥控器的type-c口为遥控器充电；



### 		操控方式：

​					以屏幕显示方向为正方向，如下图所示数字标号							![image-20261031213500666](https://cdn.jsdmirror.com/gh/yuanguMC/img-bed@main/images/image-20261031213500666.png)

​					1——云台顺时针旋转（按下切换）							3——底盘前进（按住）

​					2——云台逆时针旋转（按下切换）							4——底盘后退（按住）

​					7——云台加速（按下）												5——底盘减速（按下）		

​					8——云台减速（按下）												6——底盘加速（按下）
